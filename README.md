### 👨‍💻 About Me

I am a **Systems Programmer**, **Android Kernel Developer**, and the founder/maintainer of the **H-K-Systems** **HKS** project. My core focus lies in low-level Android security, custom Linux kernel architecture, standalone reverse-engineering utilities, and system-level tools.

- 🛠️ **Custom Kernel & ROM Engineering:** Maintainer of optimized Exynos/Snapdragon kernels with integrated low-level root frameworks (**ReSukiSU**, **KernelSU Next**, **SusFS**).
- ⚙️ **Systems Programming:** Building standalone, zero-dependency tools and utilities using **Go**, **Python**, **C/C++**, **Java**, and **Smali**.
- 🔐 **Security & Automation:** Bypassing AVB/DM-Verity protections, reverse-engineering Android binaries, LSPosed modules development, and setting up multi-architecture build pipelines in GitLab CI/CD.
